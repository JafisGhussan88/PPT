Pendahuluan

Komputer telah menjadi bagian penting dalam berbagai bidang kehidupan, mulai dari pendidikan, bisnis hingga hiburan. Istilah komputer (computer) diambil dari bahasa Latin computare yang berarti menghitung.

Menurut Blissmer (1985), komputer adalah suatu alat elektronik yang mampu melakukan beberapa tugas, yaitu menerima input, memproses input sesuai dengan instruksi yang diberikan, menyimpan perintah-perintah dan hasil pengolahannya serta menyediakan output dalam bentuk informasi.

Hardware

Perangkat keras fisik seperti CPU, memory, input/output, dan bus yang terhubung melalui motherboard.

Software

Perangkat lunak yang menjalankan instruksi dan mengolah data.

Brainware

Pengguna yang mengoperasikan dan mengendalikan sistem komputer.

Arsitektur PC Modern

Diagram blok arsitektur PC modern (Sumber: Ilustrasi)

Penjelasan Komponen (1-9)

  • Processor: Komponen utama yang menjalankan instruksi dan mengolah data.
  • Cache: Memori berkecepatan tinggi di dalam processor.
  • GPU: Mengolah dan menghasilkan tampilan grafis.
  • Monitor: Perangkat output visual dari GPU.
  • Memory: Tempat penyimpanan data sementara.
  • Memory Controller: Mengatur komunikasi antara memory dengan sistem.
  • AGP Controller: Menghubungkan kartu grafis melalui slot AGP.
  • FSB (Front Side Bus): Jalur komunikasi utama ke Northbridge.
  • Northbridge: Chipset yang mengatur komunikasi processor, memory, dan grafis.

Penjelasan Komponen (10-18)

  • Southbridge: Mengatur komunikasi dengan perangkat I/O.
  • Firewire Drive: Perangkat penyimpanan via Firewire.
  • Firewire Controller: Pengendali komunikasi Firewire.
  • USB Drive: Perangkat penyimpanan via USB.
  • USB Controller: Mengatur komunikasi perangkat USB.
  • Network Controller: Mengatur koneksi jaringan komputer.
  • PCI Bus: Jalur komunikasi ke perangkat PCI.
  • Optical Drive: Membaca/menulis data pada CD/DVD.
  • IDE Controller: Antarmuka untuk HDD/Optical.

Penjelasan Komponen (19-28)

  • PCI-ISA Bridge: Menghubungkan bus PCI dengan ISA.
  • Serial Port: Port komunikasi serial.
  • ISA Bus: Jalur komunikasi generasi lama.
  • PATA/SATA: Standar koneksi penyimpanan.
  • Parallel Port: Mengirimkan beberapa bit data sekaligus.
  • RTC (Real-Time Clock): Menjaga waktu dan tanggal komputer.
  • MCA Controller: Pengendali perangkat Micro Channel Architecture.
  • FDD (Floppy Disk Drive): Membaca/menulis floppy disk.
  • Optical Drive: Drive CD/DVD kedua.
  • SCSI Controller: Antarmuka perangkat penyimpanan kecepatan tinggi.

Penjelasan Komponen (29-36)

  • HDD: Media penyimpanan magnetik (sisi kiri).
  • Tape/Backup Drive: Backup data pita magnetik (kiri).
  • HDD: Media penyimpanan magnetik (tengah).
  • Tape/Backup Drive: Backup data pita magnetik (tengah).
  • Keyboard: Perangkat input huruf dan perintah.
  • MCA Bus: Jalur komunikasi perangkat MCA.
  • Mouse: Perangkat input penggerak kursor.
  • PS/2 Controller: Pengendali keyboard dan mouse PS/2.

Kesimpulan

Komputer adalah alat elektronik yang mampu menerima input, memproses sesuai instruksi, menyimpan perintah dan hasil olahan, serta mengeluarkan output informasi.

Arsitektur komputer merupakan susunan dan hubungan antar komponen yang bekerja bersama. Pada PC modern, setiap komponen memiliki peran penting dalam komunikasi dan pengolahan data, mulai dari processor dan cache sebagai pusat pemrosesan, memory sebagai penyimpanan, hingga Northbridge dan Southbridge yang mengatur lalu lintas data.
