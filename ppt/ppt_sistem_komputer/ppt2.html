📖 Pendahuluan

💡 Definisi Komputer

Istilah komputer berasal dari bahasa Latin computare yang berarti menghitung. Menurut Blissmer (1985), komputer adalah alat elektronik yang mampu menerima input, memproses sesuai instruksi, menyimpan perintah dan hasil olahan, serta menyediakan output dalam bentuk informasi.

Pada dasarnya komputer bekerja dengan menerima data, mengolahnya, menyimpan hasilnya, lalu menampilkannya sebagai informasi.

⚙️ Tiga Komponen Utama

  • Hardware — perangkat keras fisik seperti CPU, memory, input/output, dan bus yang terhubung melalui motherboard.
  • Software — perangkat lunak yang menjalankan instruksi.
  • Brainware — pengguna yang mengoperasikan sistem.

Ketiganya saling terikat dan tidak dapat dipisahkan.

🧩 Penjelasan Komponen (1–18)

⚡ Prosesor & Memori

  • Processor — komponen utama yang menjalankan instruksi dan mengolah data.
  • Cache — memori berkecepatan tinggi di dalam processor untuk mempercepat kerja.
  • GPU — mengolah dan menghasilkan tampilan grafis.
  • Monitor — perangkat output visual dari GPU.
  • Memory — penyimpanan data sementara yang sedang digunakan.
  • Memory Controller — mengatur komunikasi antara memory dengan sistem.
  • AGP Controller — menghubungkan kartu grafis melalui slot AGP.

🔗 Bus & Chipset

  • FSB (Front Side Bus) — jalur komunikasi utama antara Processor, AGP Controller, dan Memory Controller ke Northbridge.
  • Northbridge — chipset yang mengatur komunikasi antara processor, memory, dan grafis.
  • Southbridge — chipset yang mengatur komunikasi dengan perangkat I/O seperti USB, SATA, dan PCI.
  • Firewire Drive — perangkat penyimpanan/periferal dengan antarmuka Firewire.
  • Firewire Controller — pengendali komunikasi untuk perangkat Firewire.
  • USB Drive — perangkat penyimpanan yang terhubung via USB.
  • USB Controller — mengatur komunikasi perangkat USB dengan komputer.
  • Network Controller — mengatur koneksi jaringan komputer.

🧩 Penjelasan Komponen (19–36)

💾 Penyimpanan & Port

  • PCI Bus — jalur komunikasi utama yang menghubungkan Southbridge dengan perangkat PCI.
  • Optical Drive — membaca/menulis data pada CD atau DVD.
  • IDE Controller — antarmuka untuk menghubungkan HDD/Optical.
  • PCI-ISA Bridge — jembatan antara bus PCI dan bus ISA.
  • Serial Port — port komunikasi serial.
  • ISA Bus — jalur komunikasi generasi lama untuk perangkat ekspansi ISA.
  • PATA/SATA — standar koneksi untuk perangkat penyimpanan hard disk.
  • Parallel Port — port yang mengirimkan beberapa bit data secara bersamaan.

🖱️ Periferal & Lainnya

  • RTC (Real-Time Clock) — menjaga waktu dan tanggal komputer.
  • MCA Controller — pengendali untuk perangkat Micro Channel Architecture.
  • FDD (Floppy Disk Drive) — membaca/menulis data pada floppy disk.
  • Optical Drive (2) — drive optik kedua.
  • SCSI Controller — antarmuka untuk perangkat penyimpanan kecepatan tinggi.
  • HDD — media penyimpanan data menggunakan piringan magnetik.
  • Tape/Backup Drive — perangkat backup data menggunakan pita magnetik.
  • Keyboard — perangkat input untuk memasukkan huruf dan perintah.
  • MCA Bus — jalur komunikasi untuk perangkat berbasis MCA.
  • Mouse — perangkat input untuk menggerakkan kursor.
  • PS/2 Controller — pengendali komunikasi untuk keyboard dan mouse PS/2.

📌 Kesimpulan

✅ Poin Penting

  • Komputer adalah alat elektronik yang menerima input, memproses sesuai instruksi, menyimpan perintah & hasil, serta mengeluarkan output informasi.
  • Arsitektur komputer merupakan susunan dan hubungan antara berbagai komponen yang bekerja bersama.
  • Pada arsitektur PC modern, setiap komponen memiliki peran dalam komunikasi dan pengolahan data — mulai dari processor dan cache sebagai pusat pemrosesan, memory sebagai penyimpanan, hingga chipset dan bus yang menghubungkan semuanya.

“Memahami arsitektur komputer adalah fondasi untuk menguasai sistem komputer secara menyeluruh.”
