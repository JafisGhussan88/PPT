Pendahuluan

Komputer telah menjadi bagian penting dalam berbagai bidang kehidupan, mulai dari pendidikan, bisnis hingga hiburan. Istilah komputer berasal dari bahasa Latin computare yang berarti menghitung.

Hardware

Perangkat keras fisik seperti CPU, memory, input/output, dan bus yang terhubung melalui motherboard.

Software

Perangkat lunak yang memberikan instruksi kepada hardware untuk menjalankan tugas tertentu.

Brainware

Pengguna manusia yang mengoperasikan dan mengendalikan sistem komputer.

Tujuan

Memahami bagian komputer, membedakan input/output, dan mengenal arsitektur PC modern.

Daftar Singkatan Komponen

  • GPU = Graphics Processing Unit
  • AGP = Accelerated Graphics Port
  • HDD = Hard Disk Drive
  • FDD = Floppy Disk Drive
  • FSB = Front Side Bus
  • USB = Universal Serial Bus
  • PCI = Peripheral Component Interconnect
  • RTC = Real-Time Clock
  • PATA = Parallel Advanced Technology Attachment
  • SATA = Serial Advanced Technology Attachment
  • ISA = Industry Standard Architecture
  • IDE = Integrated Drive Electronics
  • MCA = Micro Channel Architecture
  • PS/2 = Personal System/2

Setiap komponen saling terhubung melalui bus dan controller untuk komunikasi data.

Penjelasan Komponen (1-9)

  • Processor: Komponen utama yang menjalankan instruksi dan mengolah data.
  • Cache: Memori berkecepatan tinggi di dalam processor.
  • GPU: Mengolah dan menghasilkan tampilan grafis.
  • Monitor: Perangkat output untuk menampilkan visual.
  • Memory: Penyimpanan data sementara yang sedang digunakan.
  • Memory Controller: Mengatur komunikasi antara memory dan sistem.
  • AGP Controller: Menghubungkan kartu grafis melalui slot AGP.
  • FSB: Jalur komunikasi utama ke Northbridge.
  • Northbridge: Chipset yang mengatur komunikasi processor, memory, dan grafis.

Penjelasan Komponen (10-18)

  • Southbridge: Mengatur komunikasi dengan perangkat I/O.
  • Firewire Drive: Perangkat penyimpanan via Firewire.
  • Firewire Controller: Pengendali komunikasi Firewire.
  • USB Drive: Perangkat penyimpanan via USB.
  • USB Controller: Pengendali komunikasi perangkat USB.
  • Network Controller: Mengatur koneksi jaringan komputer.
  • PCI Bus: Jalur komunikasi untuk perangkat PCI.
  • Optical Drive: Membaca/menulis data pada CD/DVD.
  • IDE Controller: Antarmuka untuk HDD/Optical.

Penjelasan Komponen (19-27)

  • PCI-ISA Bridge: Menghubungkan bus PCI dengan bus ISA.
  • Serial Port: Port komunikasi serial.
  • ISA Bus: Jalur komunikasi generasi lama.
  • PATA/SATA: Standar koneksi hard disk.
  • Parallel Port: Mengirimkan beberapa bit secara bersamaan.
  • RTC: Menjaga waktu dan tanggal komputer.
  • MCA Controller: Pengendali perangkat Micro Channel.
  • FDD: Membaca/menulis data pada floppy disk.
  • Optical Drive: Drive CD/DVD kedua.
  • SCSI Controller: Antarmuka perangkat penyimpanan kecepatan tinggi.

Penjelasan Komponen (28-36)

  • HDD (kiri): Media penyimpanan piringan magnetik.
  • Tape/Backup Drive (kiri): Backup data pita magnetik.
  • HDD (tengah): Media penyimpanan piringan magnetik.
  • Tape/Backup Drive (tengah): Backup data pita magnetik.
  • Keyboard: Perangkat input huruf dan perintah.
  • MCA Bus: Jalur komunikasi perangkat MCA.
  • Mouse: Perangkat input penggerak kursor.
  • PS/2 Controller: Pengendali keyboard dan mouse PS/2.

Kesimpulan

Komputer adalah alat elektronik yang mampu menerima input, memproses sesuai instruksi, menyimpan perintah dan hasil pengolahan, serta mengeluarkan output dalam bentuk informasi.

Arsitektur komputer merupakan susunan dan hubungan antar komponen yang bekerja bersama.

Setiap komponen memiliki peran dalam komunikasi dan pengolahan data.

Processor dan cache sebagai pusat pemrosesan, memory sebagai penyimpanan.
