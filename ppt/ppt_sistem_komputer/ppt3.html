Pendahuluan

Komputer telah menjadi bagian penting dalam berbagai bidang kehidupan, mulai dari pendidikan, bisnis hingga hiburan. Istilah komputer (computer) diambil dari bahasa Latin computare yang berarti menghitung (to compute atau to reckon).

Menurut Blissmer (1985), komputer adalah suatu alat elektronik yang mampu melakukan beberapa tugas, yaitu menerima input, memproses input sesuai dengan instruksi yang diberikan, menyimpan perintah-perintah dan hasil pengolahannya serta menyediakan output dalam bentuk informasi.

Pada dasarnya komputer bekerja dengan menerima data, mengolahnya, menyimpan hasilnya lalu menampilkannya sebagai informasi.

Proses tersebut hanya dapat berjalan jika perangkat keras (Hardware), perangkat lunak (Software) dan pengguna (Brainware) sebagai komponen yang saling terikat dan tidak bisa dipisahkan.

Perangkat keras terdiri atas banyak komponen seperti CPU, memory, input dan output serta jalur komunikasi (bus) yang menghubungkannya, semua komponen ini terpasang dan terhubung melalui motherboard.

Arsitektur PC Modern

[Gambar Arsitektur PC Modern]

Processor • GPU • Memory • Northbridge • Southbridge • PCI Bus • ISA Bus • dan komponen lainnya

Setiap komponen saling terhubung melalui jalur bus yang menghubungkan processor, memory, dan perangkat I/O.

Penjelasan Komponen (1/2)

  • Processor: Komponen utama yang menjalankan instruksi dan mengolah data komputer.
  • Cache: Memori berkecepatan tinggi di dalam processor untuk mempercepat kerja prosesor.
  • GPU: Komponen yang mengolah dan menghasilkan tampilan grafis.
  • Monitor: Perangkat output untuk menampilkan visual dari GPU.
  • Memory: Tempat penyimpanan data sementara yang sedang digunakan komputer.
  • Memory Controller: Pengendali yang mengatur komunikasi antara memory dengan sistem.
  • AGP Controller: Pengendali untuk menghubungkan kartu grafis melalui slot AGP.
  • FSB/Front Side Bus: Jalur komunikasi utama yang menghubungkan Processor, AGP Controller, dan Memory Controller ke Northbridge.
  • Northbridge: Chipset yang mengatur komunikasi antara processor, memory, dan grafis.
  • Southbridge: Chipset yang mengatur komunikasi dengan perangkat I/O seperti USB, SATA, dan PCI.
  • Firewire Drive: Perangkat penyimpanan/periferal yang menggunakan antarmuka Firewire.
  • Firewire Controller: Pengendali komunikasi untuk perangkat Firewire.
  • USB Drive: Perangkat penyimpanan yang terhubung via USB.
  • USB Controller: Pengendali yang mengatur komunikasi perangkat USB dengan komputer.
  • Network Controller: Komponen yang mengatur koneksi jaringan komputer.
  • PCI Bus: Jalur komunikasi utama yang menghubungkan Southbridge dengan perangkat-perangkat PCI.

Penjelasan Komponen (2/2)

  • Optical Drive: Perangkat untuk membaca atau menulis data pada CD atau DVD.
  • IDE Controller: Antarmuka untuk menghubungkan perangkat penyimpanan HDD/Optical.
  • PCI-ISA Bridge: Jembatan yang menghubungkan bus PCI dengan bus ISA.
  • Serial Port: Port untuk menghubungkan perangkat menggunakan komunikasi serial.
  • ISA Bus: Jalur komunikasi generasi lama untuk perangkat ekspansi ISA.
  • PATA/SATA: Standar koneksi untuk perangkat penyimpanan hard disk.
  • Parallel Port: Port yang mengirimkan beberapa bit data secara bersamaan.
  • RTC/Real-Time Clock: Komponen yang menjaga waktu dan tanggal komputer.
  • MCA Controller: Pengendali untuk perangkat dengan standar Micro Channel Architecture.
  • FDD/Floppy Disk Drive: Perangkat untuk membaca dan menulis data pada floppy disk.
  • SCSI Controller: Antarmuka untuk menghubungkan berbagai perangkat penyimpanan kecepatan tinggi.
  • HDD: Media penyimpanan data menggunakan piringan magnetik.
  • Tape/Backup Drive: Perangkat untuk backup data menggunakan pita magnetik.
  • Keyboard: Perangkat input untuk memasukkan huruf dan perintah.
  • MCA Bus: Jalur komunikasi yang digunakan oleh perangkat berbasis MCA.
  • Mouse: Perangkat input untuk menggerakkan kursor.
  • PS/2 Controller: Pengendali komunikasi untuk keyboard dan mouse PS/2.

Kesimpulan

Komputer adalah alat elektronik yang mampu melakukan beberapa tugas yaitu menerima input, memproses input sesuai dengan instruksi yang diberikan, menyimpan perintah-perintah dan hasil pengolahannya mengeluarkan output dalam bentuk informasi.

Berdasarkan laporan yang telah kami buat, dapat disimpulkan bahwa arsitektur komputer merupakan susunan dan hubungan antara berbagai komponen komputer yang bekerja. Pada arsitektur PC modern setiap komponen memiliki peran dalam proses komunikasi dan pengolahan data mulai dari processor dan cache sebagai pusat pemrosesan, memory sebagai penyimpanan.
